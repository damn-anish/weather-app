**Weather App**

Built this weather app to be fast and simple, it grabs your exact location and pulls up the current forecast instantly, you can also just type in a city name if you'd rather search manually. 

**FEATURES**

Search weather by city
Displays current temperature
Shows weather conditions
Displays humidity
Shows wind speed
Responsive design for different screen sizes
Clean and colorful user interface
Fast and simple to use

**Built With**

**HTML** – Structure of the website

**CSS** – Styling, layout, animations, and responsiveness

**JavaScript** – Weather data, search functionality, and interactions

**Weather API** – Fetches real-time weather information
