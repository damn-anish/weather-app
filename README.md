#  Weather App

A simple and responsive **Weather App** built with HTML, CSS, and JavaScript.  
It allows users to search for a city and view its current weather information through a clean and colorful interface.

##  Features

- Search weather by city
-  Displays current temperature
-  Shows weather conditions
-  Displays humidity
-  Shows wind speed
-  Responsive design for different screen sizes
-  Clean and colorful user interface
-  Fast and simple to use

##  Built With

- **HTML** – Structure of the website
- **CSS** – Styling, layout, animations, and responsiveness
- **JavaScript** – Weather data, search functionality, and interactions
- **Weather API** – Fetches real-time weather information

##  How to Run

1. Clone this repository:

```bash

```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it!
